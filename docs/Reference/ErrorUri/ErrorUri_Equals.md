# ErrorUri.Equals(ErrorUri) Method
## Definition
Namespace: [Maple.Result](../namespace.md)<br>
Assembly: Maple.Result.dll<br>
Source: <a href="https://github.com/TomMaple/Result/blob/main/src/Maple.Result/ErrorUri.cs#L118" target="_blank">ErrorUri.cs</a>

Determines whether the specified [ErrorUri](ErrorUri.md) is equal to the current [ErrorUri](ErrorUri.md), comparing the [Value](ErrorUri_Value.md) property rather than the underlying field.

```csharp
public bool Equals(ErrorUri other);
```

### Parameters
#### `other` [ErrorUri](ErrorUri.md)
The [ErrorUri](ErrorUri.md) to compare with the current instance.

### Returns
[Boolean](https://learn.microsoft.com/dotnet/api/system.boolean)

`true` if the specified [ErrorUri](ErrorUri.md) is equal to the current one; otherwise, `false`.

## Remarks
Two [ErrorUri](ErrorUri.md) instances are equal when their [Value](ErrorUri_Value.md) properties are equal.

> [!NOTE]
> The default record equality generated by the compiler would compare the underlying field, which is `null` for a default instance and `about:blank` for the one returned by [None()](ErrorUri_None.md). Those two instances report the same [Value](ErrorUri_Value.md), so comparing the field would report them as *not equal* despite being indistinguishable through the public API. This method overrides that behavior to compare the [Value](ErrorUri_Value.md) instead.

This override is consistent with [GetHashCode()](ErrorUri_GetHashCode.md): equal [ErrorUri](ErrorUri.md) instances always produce the same hash code.

## Examples
```csharp
// true — a default instance reports `about:blank`, just like None().
var areEqual = default(ErrorUri) == ErrorUri.None();
```

```csharp
// true — a null value is treated as an unspecified type, i.e., `about:blank`.
var areEqual = new ErrorUri(null!) == ErrorUri.None();
```

```csharp
// false — the values differ.
var areEqual = ErrorUri.None() == ErrorUri.Locator("https://exampleapp.com/docs/errors/signup/email-required");
```
